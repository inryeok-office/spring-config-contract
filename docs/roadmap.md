# Roadmap

The roadmap is intentionally high-level while the project is in early development.

## v0.1

- Spring Boot 3.x compatibility
- `@ConfigurationProperties` support
- `@Value` support
- `application.yml` support
- `.env.example` support
- Docker Compose support
- Missing configuration detection
- Unused configuration detection
- Required, optional, and default handling
- Gradle integration

## After v0.1

Kubernetes, Helm, PR reporting, Maven integration, and other large integrations are post-v0.1 possibilities. Their design and scope will be evaluated after the initial contract model and supported inputs are established.
